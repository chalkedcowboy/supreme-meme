# Bloodborne slice (Unity)

Playable slice: hunter vs one beast. Copy this folder into `Assets/` of any Unity 2022+ project and press Play. The arena, player, camera, enemy and HUD are created at runtime.

| Input | Action |
|---|---|
| WASD / mouse | move / look |
| LMB | attack (landing hits regains yellow rally health) |
| RMB | pistol: shoot the beast mid-windup to stagger it (yellow), then LMB for a visceral attack |
| Space | quickstep (i-frames, costs stamina) |
| F | blood vial (5) |
| Q | lock-on |
| R | restart |

Attacks and dodges cost stamina (green bar). Wave 1 is three fast hounds; wave 2 is the beast, which enrages at half health (purple: faster, shorter telegraph). Kills drop blood echoes. The beast telegraphs attacks by turning red; quickstep through the strike.
